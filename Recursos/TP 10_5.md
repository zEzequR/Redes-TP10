1. Armar el laboratorio en función del esquema de conectividad presentado

### HA `ha.startup`
``` text
ip a add 170.16.128.1/17 dev eth0
ip r add default via 170.16.255.252

ip link set dev eth0 mtu 1200

ln -sf /shared/hosts /etc/hosts

ln -sf /shared/resolv.conf /etc/resolv.conf
```
