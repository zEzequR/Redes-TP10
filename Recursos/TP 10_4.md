# Solución

### Crear archivo resolv.conf
``` text
   /
   └── shared
      ├── resolv.conf
```

### Contenido de resolv.conf
``` text
   nameserver 8.8.8.8
```

### Configuramos eL NAT en `re.startup` para que todos los dispositivos de una red privada puedan acceder a internet a través de la interfaz 2
``` text
   iptables -t nat -A POSTROUTING -o eth2 -j MASQUERADE
```

### Escribir en todos los hosts`.startup` el siguiente comando para reemplazar el archivo original en los contenedores al momento de iniciar el laboratorio
``` text
   ln -sf /etc/resolv.conf /etc/resolv.conf
```

### Agregamos un default gateway en todos los routers para que puedan llegar al router E cuando no reciben un paquete con un destino que no se encuentra en su tabla de routeo

``` text
   ra.startup -> ip r add default via 192.168.50.130
   rb.startup -> ip r add default via 192.168.50.133
   rc.startup -> ip r add default via 192.168.50.138
   rd.startup -> ip r add default via 192.168.50.149
```
